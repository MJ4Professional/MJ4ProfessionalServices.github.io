# MJ4 Professional Services website

Free static website for GitHub Pages.

## Publish
1. Sign into GitHub as **MJ4Professional**.
2. Create a **public** repository named `MJ4Professional.github.io`.
3. Upload **all the files inside this folder** to the repository root (not a nested folder). Commit changes.
4. Open **Settings → Pages**. Under **Build and deployment**, select **Deploy from a branch**, branch **main**, folder **/(root)**, then Save.
5. Visit **https://mj4professional.github.io/** after deployment completes.

## Before going live
- Update `contact.html` with your real business contact details and remove the placeholder notice.
- Review services for accuracy; do not imply a CPA designation unless authorized.
- Replace generic About text with your verified business story and qualifications.
- Add your Google Business Profile and social links when available.
- Verify your site with Google Search Console and submit `https://mj4professional.github.io/sitemap.xml`.
- SEO settings help search engines understand pages; they do not guarantee rankings.
- For a custom domain later, update canonical, Open Graph, robots and sitemap URLs.
